# Usage examples

## Check status before work

```
git status
git diff
git log --oneline -5
```

## Stage and commit

```
git add INDEX.md AGENTS.md
git commit -m "init: project memory framework v1"
```

## Amend last commit

```
git add README.md
git commit --amend -m "init: project memory framework v1"
```

## Unstage a file

```
git restore --staged AGENTS.md
```
