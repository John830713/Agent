# mneme

Purpose: Persistent memory backend providing cross-session semantic memory storage and retrieval.

## Use cases

- Store important decisions and preferences
- Cross-session context recall
- Record milestone events
- Pin persistent rules

## Limitations

- Not suitable for large files or code
- Semantic search depends on embedding model
- Uses `~/.mneme/` as data directory
