# pycdc / pycdas

Python bytecode decompiler / disassembler (zrsx/pycdc fork).

## Use cases

- Decompile `.pyc` to readable `.py` source
- Disassemble `.pyc` to bytecode instructions
- Supports Python 2.0 ~ 3.14

## Limitations

- Some Python constructs may not fully decompile (comprehensions, decorators)
