# Result Schema — 成果目錄規範

## 必要檔案

```
result-name/
├── INDEX.md       # 成果說明書
├── summary.md     # 總結報告
└── artifacts/     # 產出檔案（程式碼、文件等）
```

## INDEX.md 格式

```markdown
# result-name

status: archived

## 來源任務

關聯的 TASK 名稱或 ID。

## 產出摘要

## 相關工具

用到的工具清單。
```

## summary.md 格式

```markdown
# 總結

## 達成目標

## 遇到的問題

## 解決方案

## 後續建議
```
