# Usage examples

## Store memory

```
remember(content="user prefers Rust over Python", type="preference")
```

## Search memory

```
recall(query="what does user think about languages")
```

## Record event

```
record_event(kind="milestone", payload={"content": "v1 launch"})
```

## Pin rule

```
pin(content="keep INDEX.md in every directory")
```

## Check status

```
stats()
```
